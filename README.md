 College XP

 Project Overview

College XP is an educational application designed to help college students manage their academic activities and improve their learning experience. The platform aims to make academic information more accessible by providing students with a central place to access learning resources and track their progress.

The project consists of an Android application and a website, supported by a backend API.

 Problem Statement

College students may experience difficulties managing their academic activities when learning resources, course information, and academic progress are spread across different platforms. This can make it challenging to stay organised, monitor progress, and access relevant educational information efficiently.

College XP aims to address this problem by providing a centralised digital platform where students can access course information, manage their learning activities, and monitor their progress.

 Problem Being Solved

College XP aims to address the following challenges:

Scattered academic information: Students may need to use multiple platforms to find relevant course information and learning resources.
  Difficulty tracking progress: Students need a convenient way to monitor their learning progress and achievements.
  Limited centralisation: Academic information and learning activities may not be available in one accessible platform.
  Student organisation: Students need digital tools that can help them manage their learning activities more effectively.

 Project Objectives

The main objectives of College XP are to:

1. Provide a user-friendly platform for college students.
2. Enable students to register and log in to the application.
3. Provide access to course information through the platform.
4. Support the tracking of student progress and experience points (XP).
5. Connect the Android application and website to a backend API.
6. Improve the accessibility and organisation of academic information.

 Main Features

The project is designed to support the following features:

* Student registration and login.
* Course information management and access.
* Student progress tracking.
* Experience points (XP) and level progression.
* Android application interface.
* Website interface.
* Backend API integration.

*Note: The availability of individual features depends on the current implementation of the project.*

 Technologies Used

The project uses the following technologies across its components:

  Android Studio: Android application development.
  Kotlin: Android application programming.
  Firebase Authentication: User authentication.
  Spring Boot: Backend API development.
  Java: Backend development.
  React: Website user interface.
  TypeScript: Website application logic.
  Git and GitHub: Source code management and version control.

 Project Structure

The project consists of three main components:

 1. Android Application

The Android application provides the mobile interface through which students can interact with College XP.

 2. Website

The website provides a web-based interface for accessing College XP functionality.

 3. Backend API

The backend API handles communication between the application, website, and backend services. It includes components for managing student and course information.

 Installation and Setup

 Android Application

1. Clone or download the Android application repository.
2. Open the project in Android Studio.
3. Allow Gradle to sync the project dependencies.
4. Configure the required Firebase settings.
5. Run the application on an Android emulator or compatible device.

 Backend API

1. Open the backend project in your preferred Java development environment.
2. Configure the application properties and any required database settings.
3. Ensure the necessary dependencies are installed.
4. Run the Spring Boot application.
5. Verify that the API endpoints are accessible.

 Website

1. Open the website project in your code editor.
2. Install the project dependencies using the package manager specified by the project.
3. Configure the backend API URL.
4. Start the website using the project's development command.
